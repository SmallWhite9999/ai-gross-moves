# 每天被 AI 噁心的 bug 紀錄

我是做台股量化的，每天寫 code、跑研究，大部分 code 是叫 AI 寫的。
AI 很好用，但也每天都在用各種方式噁心我。

這裡一天記一個當天真的遇到的 bug：

- **bug 是什麼**：AI 說了什麼、實際發生什麼
- **怎麼抓到的**
- **我的解法**：當下怎麼修，之後怎麼防

每個案例配一張圖。X 上的貼文是短版，完整的放這裡。

只分享踩坑跟解法，不報明牌，不放實單、部位跟研究的報酬數字。
